## 迭代历程（浓缩）

设计是在一系列编号设计文档（原 `memory-arch` 系列的 001–010）加外部架构评审中逐步成型的：

- **001–003** —— 设计决策、证据/实验、服务路线图，确立了“两种记忆”模型与“挣得式信任”生命周期。
- **004** —— 首次实现状态：日记 + 存储 + 服务 + 最初的工具面。
- **005** —— 围绕 **生·用·修·记** 的整合版*最终设计*，实现即依此展开。
- **006–010** —— 多轮增量：经验生命周期加固、账本、工作台 UI、**第二轮**（事实去重 + 佐证、关心事项**背景**、`thinking` 类别、画像快照注入），最终落在 **schema v5**。

## ✅ 已实现

**核心存储与生命周期**
- 进程级全局 SQLite 库（`memory.db`），被所有会话共享；增量 schema 迁移（现 **v5**）。
- **日记**：只增不删的原始条目（`memory_fact`）。
- **提炼**：`memory_extract` 把日记蒸馏成**事实**与**关心事项**。
- **经验生命周期**：`memory_ingest`、`memory_report`、`memory_revise`、`memory_refine`、`memory_verify`、回滚；信任靠上报的使用挣得，凭证据晋升/降级。
- **召回**：`memory_recall` —— 在全局库上做关键词/情境相关性匹配，支持可选 `context` 收窄。
- **账本**：只增不删的审计轨迹（`memory_ledger`、`memory_verify`）。
- **整合**：`memory_consolidate` 做周期性清理。

**语义记忆（事实与关心事项）**
- 九个以用户为中心的事实类别。
- **事实去重**：相同类别+键+值合并为一条，累加佐证计数、合并来源日记 id。
- 关心事项类别：todo / **思考** / 想法 / 问题 / 决定 / 承诺 / 其他。
- 关心事项**背景**场景（schema v5），让 agent 明白某件事为何重要。
- 关心事项状态 + 树形结构；支持按条件列表与计数。

**集成与界面**
- **画像快照注入**：把头部事实 + 未了心事作为专门段落注入系统提示词。
- **浏览器工作台**：事实日记、经验、账本、人工运维四个页面，带筛选与分页。
- **人工运维**：手动晋升 / 降级 / 置顶 / 编辑 / 删除，均记入账本。
- **远端 API**：一套 typert remote 面，让浏览器端与 host 存储对话。
- **`memory-extraction` skill**：随包附带的引导，教 agent 何时/如何高质量提炼。

**打包（本仓库）**
- 可分发安装包 `dsh-daoing-memory`，带 `dsh.bundle.patch` 实现 profile 自动接线。
- `lib/` 里自带预构建的 host + 浏览器产物（安装不做构建）。
- 一条命令放置 skill 的辅助脚本（`scripts/install-skill.mjs`）。

## 🚧 尚未实现

- **向量辅助召回。** 召回目前只有关键词/情境相关性，没有向量索引。
- **跨 agent / 多租户隔离。** 存储是单一进程级全局库。
- **自动遗忘。** 衰减/遗忘是显式的（人工或整合），不是策略驱动。
- **关心事项自动了结。** 当底层 todo/问题已被解决时，关心事项还不会自动关闭。
- **经验语义去重。** 事实有去重；近似重复的经验尚不会自动合并。
- **完全解耦的独立构建。** 产物由 DSH 构建工具链产出并以预构建形式随包发布；本仓库尚不能脱离 monorepo 从源码自行重建（见 BUILDING）。

## 🧭 扩展方向

大致按杠杆从高到低排序：

1. **向量辅助召回** —— 用向量索引增强（而非取代）关键词相关性，做模糊匹配，同时保留“可信库”的治理。
2. **完全独立构建** —— 内联（vendoring）构建工具链，让包能脱离 DSH monorepo 从源码重建，实现真正独立迭代。
3. **整合策略** —— 面向长期记忆的衰减、冷存储与压实启发式。
4. **关心事项生命周期自动化** —— 检测某个关心事项的闭环已达成，并提出了结建议。
5. **经验语义去重** —— 合并近似重复的经验族。
6. **多租户范围** —— 在全局库之上叠加按用户/按 agent 的隔离。
7. **市场成熟度** —— 发布到 npm、上架 DSH 插件市场、CI 构建/发布。
8. **i18n 与更多事实类别** —— 拓宽以用户为中心的类别体系。
